# Feedback log

Every triaged issue gets one row here, so feedback can be counted instead of remembered.
The `triage-feedback` skill (`.claude/skills/triage-feedback/`) keeps this file up to date.

## Design ratings

One row per design-feedback issue. The rating is the reporter's 1-5 answer; the area maps to the
[review rubric](../design-system/review-rubric.md) sections.
