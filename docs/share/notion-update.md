## 용도별 파일럿 4종 · 테마 3종 · 다국어 · 논문 기반 개선

**한 줄 요약.** 리포트를 매번 새로 만들지 않도록, 용도별로 완성된 파일럿을 미리 만들어 두고
"용도 → 테마 → 언어" 세 가지만 물은 뒤 파일럿을 복사해 필드만 바꾸게 했다. 에이전트가 쓰는 명세는 1~3K 토큰이다.

### 무엇을 만들었나
- **파일럿 4종**: 대시보드(경영 요약) · 지표 테이블(측정값 입력 매트릭스) · 지표 확인(행렬 히트맵·성적표) · 딥다이브(요인 분해·분포·원천 행)
- **테마 3종**: 네이비 · 페이퍼 · 미드나잇 — 토큰 파일 하나에서 생성, 공식 테마 스키마 통과
- **다국어**: 기본 영어, 한국어 내장. 화면 글자·필드 이름·숫자 단위(M/K ↔ 만/억)·결론 문장·데이터 값까지 언어별로 바뀐다
- **시작 흐름**: `new_report.py` + 스킬. 파일럿을 복사하면서 한 언어만 남기고, 대상 모델에 없는 필드만 알려 준다

### 숫자
- 검증: 파일럿 4종 + 한국어 예제 모두 공식 PBIR 검증 오류 0 · 경고 0
- 명세 크기: 행렬 1.3K · 테이블 1.9K · 딥다이브 2.0K · 대시보드 3.4K 토큰 (생성물의 약 6%)

### 틀린 것과 배운 것
- 영어 숫자 서식 `#,0.0,,"M"`의 쉼표 스케일링을 Desktop이 무시했다 → 측정값에서 나누는 방식으로 통일
- DAX 변수 이름 `top`에서 구문 오류 → 이름을 바꿨다
- 합계 줄·드롭다운에 "합계", "모두"가 보였다 → Desktop 표시 언어를 따라가는 글자. 합계 이름은 리포트 언어로 고정
- 캡처 스크립트가 페이지 탭을 위치로 추정하다 리본 탭을 눌렀다 → 페이지 이름을 생성된 리포트에서 읽게 바꿨다
