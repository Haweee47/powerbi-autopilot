# 디자인 리뷰 채점표

스크린샷(과 필요하면 PBIR JSON)을 보고 대시보드를 채점한다. 근거는 [principles.md](principles.md)에 있다.

- 항목마다 **0 = 안 됨 · 1 = 부분적으로 됨 · 2 = 됨**으로 매긴다. 만점은 48점 (페이지가 하나뿐이면 G를 빼고 40점).
- **치명(★)** 항목이 하나라도 0점이면 점수와 관계없이 "완성" 불가. 고친 뒤 다시 캡처한다.
- 결과는 `문제 · 위치 · 심각도 · 고칠 방법` 형식으로 남긴다.

## A. 목적과 위계 (8점)

| # | 항목 | 확인 방법 |
|---|---|---|
| A1 ★ | 페이지가 답하는 질문 하나를 한 문장으로 말할 수 있다 | 헤더의 인사이트 문장이 그 질문에 답하는지 |
| A2 | 요약 → 맥락 → 상세 순서로 위에서 아래로 내려간다 | 맨 위가 KPI, 가운데가 차트, 아래가 표 |
| A3 | 시각 묶음이 경영 요약 4~6개, 그 외 7±2개 이내다 | 묶음 수 세기 (도형·텍스트 제외) |
| A4 | KPI는 3~5개이고, 모두 비교 기준(전년·목표)을 달고 있다 | 카드마다 증감이나 목표 대비가 있는지 |

## B. 레이아웃 (8점)

| # | 항목 | 확인 방법 |
|---|---|---|
| B1 ★ | 비주얼끼리 겹치지 않고 모두 캔버스 안에 있다 | 스크린샷 + JSON의 x+width, y+height |
| B2 | 모든 좌표·크기가 8의 배수다 | JSON position 값 |
| B3 | 같은 단계의 간격이 모두 같고, 묶음 안 간격 < 묶음 사이 간격이다 | 이웃한 비주얼 사이 거리 계산 |
| B4 | 세로 경계선이 여러 줄에 걸쳐 이어진다 | 줄마다 열 경계 x 좌표 비교 |

## C. 차트 (8점)

| # | 항목 | 확인 방법 |
|---|---|---|
| C1 | 질문에 맞는 형태다 (principles 4절 표) | 차트마다 "무슨 질문?"을 적어 보기 |
| C2 ★ | 막대는 0에서 시작하고, 이중 축·3D·게이지·조각 6개 이상 파이가 없다 | 축 시작값, 비주얼 종류 |
| C3 | 막대가 의도한 순서(값 또는 이름)로 정렬돼 있다 | 스크린샷 |
| C4 | 값 레이블은 필요한 곳(끝점·극값)에만 있다 | 모든 점에 숫자가 붙어 있지 않은지 |

## D. 숫자와 글자 (6점)

| # | 항목 | 확인 방법 |
|---|---|---|
| D1 | 글자 크기가 4~5단계 이내이고 최소 9pt다 | 테마 textClasses + 직접 지정 크기 |
| D2 | 숫자가 억·만·%·%p로 3~4자리 이내로 표시된다 | KPI·축·레이블 |
| D3 | 차트 제목이 기본값("Sum of X by Y")이 아니고 인사이트나 대상을 말한다 | 제목 읽기 |

## E. 색 (6점)

| # | 항목 | 확인 방법 |
|---|---|---|
| E1 | 바탕은 중립이고 강조색은 하나다 | 스크린샷에서 눈에 띄는 색 개수 |
| E2 ★ | 색만으로 뜻을 전하지 않는다 (▲▼·부호·레이블 병행) | 증감·상태 표시 |
| E3 ★ | 글자 명암 대비 4.5:1 이상, 막대·선 3:1 이상 | 대비 계산 (색 검증 스크립트) |

## F. 맥락과 상호작용 (4점)

| # | 항목 | 확인 방법 |
|---|---|---|
| F1 | 데이터 기준일이 보이고, 걸린 필터 상태가 보인다 | 헤더·필터 줄 |
| F2 ★ | 적힌 숫자와 문장이 데이터와 일치한다 (DAX나 원본으로 대조) | 인사이트 문장의 숫자를 쿼리로 확인 |

## G. 페이지 구성과 이동 (8점, 여러 페이지일 때)

| # | 항목 | 확인 방법 |
|---|---|---|
| G1 | 페이지마다 질문 하나이고, 페이지 이름이 목적지를 말하며, 보이는 탭이 5~7개 이내다 | 페이지 목록과 이름 |
| G2 | 모든 페이지의 같은 자리에 이동 수단(페이지 선택기 우선)이 있고 현재 페이지가 표시된다 | 페이지별 스크린샷 비교 |
| G3 ★ | 드릴스루 페이지에 뒤로 가기와 선택한 항목 표시가 있고, 핵심 정보가 툴팁·책갈피 뒤에 숨어 있지 않다 | 상세 페이지 캡처, 첫 화면에 헤드라인이 보이는지 |
| G4 | 책갈피는 보기 전환에만 쓰고 8개 이내이며 데이터 옵션을 껐다. 지표 전환은 필드 매개변수로 한다 | 책갈피 목록·옵션, PBIR `bookmarks/` |

## 채점 결과 기록 형식

```yaml
page: 경영 요약
score: 41/48
critical_failures: []
findings:
  - issue: KPI 카드 간격이 16px/24px로 섞임
    location: KPI 줄 3~4번째 카드 사이
    severity: warning
    fix: 모든 KPI 간격을 16px로 통일
```

## H. 근거 기반 항목 (논문·자료, [literature.md](literature.md))

| # | 항목 | 통과 조건 | 근거 |
|---|---|---|---|
| H1 | 결론 문장이 제목 다음으로 강하다 | 흐린 회색·작은 글자가 아니다 | Kim 2021, Borkin 2016 |
| H2 | 결론이 가리키는 항목이 차트에서도 두드러진다 | 같은 항목이 색·위치로 강조된다 | Kim 2021 |
| H3 | 선 차트 계열 이름이 선 옆에 있다 | 범례를 오가며 읽지 않는다 | 시선 추적 연구 |
| H4 | 지금 보는 범위(기간·필터)가 제목 줄에 보인다 | 필터를 바꾸면 문구도 바뀐다 | Bach 2023 메타 정보 |
| H5 | 모든 KPI에 비교 기준이 있다 | 숫자만 덩그러니 있는 카드가 없다 | Microsoft, Few |
| H6 | 임계값은 선, 좋고 나쁨은 의미 색 | 0% 기준선·감소 빨강 | Bach 2023 |
| H7 | 비스듬한 글자가 없다 | 축 글자가 수평이다 | Microsoft, Quispel 2016 |
