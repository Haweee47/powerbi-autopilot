# 대시보드 시안 (HTML)

Power BI로 만들기 전에 [디자인 원칙](../principles.md)을 HTML로 먼저 적용해 보는 시안이다.
브라우저에서 바로 열리고, 폭에 따라 12열 → 2열 → 1열로 바뀐다. 밝은·어두운 테마를 모두 지원한다.

| 파일 | 설명 |
|---|---|
| `sales-executive-summary.src.html` | 원본. 데이터 자리는 `__DATA__`로 비워 둔다 |
| `retail-data.json` | [공용 데이터](../../examples/_data/korean-retail/README.md)를 월·카테고리·매장별로 집계한 값 (12KB) |
| `sales-executive-summary.html` | 원본에 데이터를 넣은 완성본. 이 파일을 연다 |
| `screenshots/` | 데스크톱(밝음·어두움)과 휴대폰 폭 캡처 |

## 다시 만들기

```bash
python -c "src=open('sales-executive-summary.src.html',encoding='utf-8').read(); data=open('retail-data.json',encoding='utf-8').read().strip(); open('sales-executive-summary.html','w',encoding='utf-8').write(src.replace('__DATA__',data))"
```

숫자는 예제 03 모델의 DAX 검증값과 같다.
- 2026년 1~8월 매출 841,775,565원, 전년 829,505,235원
- 목표 879,000,000원

## 원칙을 어디에 적용했나

| 원칙 (principles.md) | 시안에서 |
|---|---|
| 한 페이지 질문 하나, 제목은 인사이트 문장 | 헤더 문장 "1–8월 누계 매출 8.4억, 전년보다 ▲1.5% · 목표의 95.8%"와 카드 제목이 필터에 따라 다시 쓰인다 |
| 요약 → 맥락 → 상세 | KPI 4개 → 월별 추이·카테고리 → 권역·매장 |
| 시각 묶음 4~6개, KPI 3~5개 | KPI 줄 + 차트 4개 = 5묶음, KPI 4개 |
| 모든 숫자에 비교 기준 | KPI마다 전년 대비·목표 대비, 12개월 추이선 |
| 목표가 없는 수준에선 달성률 숨김 | 채널 필터를 걸면 목표 달성률은 "—"로, 카테고리 차트는 전년 대비로 바뀐다 |
| 여백 3단계 (16 · 24 · 32) | 묶음 안 16px, 묶음 사이 24px, 바깥 여백 최대 32px |
| 질문이 형태를 정한다 | 추이 = 선, 목표 대비 = 발산 막대, 크기 = 정렬된 막대, 예외 = 표 |
| 강조색 하나 + 회색 | 올해는 파랑, 작년은 회색, 목표는 점선 |
| 색만으로 뜻을 전하지 않음 | 모든 증감에 ▲▼와 부호. 좋음은 파랑, 나쁨은 빨강 (색 검증 스크립트 통과) |
| 한국어 표기 | 억·만 단위, 비율 차이는 %p, 조사(이/가, 은/는)를 받침에 맞춰 자동으로 붙임 |
| 필터 한 줄, 모든 것에 적용 | 기간(1–8월 누계 / 8월)과 채널이 모든 카드에 적용된다 |
| 툴팁은 보조, 표 보기 | 추이 차트는 "표로 보기", 나머지는 값이 모두 글자로 보인다 |
| 아직 오지 않은 기간 제외 | 9~12월은 올해 선이 없고, 목표 비교도 8월까지만 한다 |

## Power BI로 옮길 때

- 캔버스는 1280×720 한 장이다. HTML의 12열 폭을 8px 배수 좌표로 바꾼다 (바깥 여백 32, 간격 16).
- CSS 토큰은 테마 JSON으로 옮긴다.
  - 색: `--page` → `background`, `--surface` → 비주얼 배경, `--accent` → `dataColors[0]`, `--pos`/`--neg` → `good`/`bad`
  - 글자 단계 → `textClasses`
- 글꼴: Windows에서는 Segoe UI에 한글 글자가 없어 맑은 고딕으로 대체된다. Power BI Desktop과 같은 조건이다.
- **휴대폰 화면은 Power BI가 자동으로 만들어 주지 않는다.** HTML 1열 배치 순서를 따라 KPI → 추이 → 카테고리 순으로 휴대폰 화면을 따로 배치한다.
- 매장 표의 "양 끝 3개씩"은 Power BI에서 상위 N 필터 두 개(오름차순·내림차순)로 만든다.
