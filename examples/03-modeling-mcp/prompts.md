# 03 — Power BI Modeling MCP만 사용

- 사용 도구: [microsoft/powerbi-modeling-mcp](https://github.com/microsoft/powerbi-modeling-mcp) `0.5.0-beta.13` (저장소 커밋 `31f2881`)
- 규칙: 이 MCP 하나만 쓴다. 다른 스킬·CLI는 쓰지 않는다.
- 한계: README에 "리포트 페이지는 수정할 수 없다"고 적혀 있다. 그래서 결과물은 **모델만 담은 PBIX**다.
  대신 이 MCP의 강점인 모델 품질(관계·측정값·DAX 검증)과 모델 문서를 결과물로 남긴다.

## 사용자가 입력한 프롬프트 (원문 그대로)

```
위 3개 깃헙을 기반으로 각각의 power bi를 만들어봐. 장점을 가져오는게 아니라 각각의 깃헙만 사용해야해. 1개씩 총 3개 만들어. pbix로
```

선택지 응답: "모델만 담은 PBIX", "한국어 가상 판매", "모두 설치" → 이후 `진행해`

## 세 예제 공통 요청문

```
2026년 8월 기준, 경영진이 한눈에 보는 판매 실적 요약 대시보드 1페이지를 만들어줘.
매출·이익·목표 달성률, 전년 대비 증감, 카테고리·채널·매장별 성과를 보여줘.
```

## 작업 순서 (Claude가 MCP로 수행)

1. 빈 Power BI Desktop 실행 → MCP `ListLocalInstances` → `Connect`
2. 모델 옵션: 자동 날짜 테이블 끄기, 암시적 측정값 억제, 모델 설명
3. M 매개변수 `데이터폴더` → CSV 가져오기 테이블 4개 → 새로 고침 → DAX로 행 수·총매출 검증
4. DAX 계산 테이블(날짜·카테고리·측정값), 계산 열(실적기간), 정렬·숨김, 날짜 테이블 지정
5. 관계 6개, 측정값 29개 → 새로 고침 → DAX 쿼리 4개로 Python 기대값과 대조 (전부 일치)
6. `ExportToTmdlFolder`로 [`tmdl/`](tmdl/) 저장, [모델 문서](model-doc.md) 작성

## 사람이 손으로 한 부분

| 단계 | 내용 | 이유 |
|---|---|---|
| 준비 | Claude Code 세션 재시작 후 MCP 서버 사용 승인 | MCP 서버는 세션 시작 때만 불러온다 |
| 저장 | Desktop에서 `파일 > 다른 이름으로 저장 > KoreanRetail.pbix` | MCP에는 파일 저장 기능이 없다 (Desktop 메모리 속 모델만 수정) |

Desktop 실행은 Claude가 셸 명령으로 했다.
