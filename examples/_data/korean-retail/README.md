# 한국어 가상 소매 판매 데이터

세 예제가 똑같이 쓰는 입력 데이터. 실존 기업·개인과 무관한 **가상 데이터**이며,
[`generate.py`](generate.py)를 실행하면 누구나 같은 결과를 얻는다 (시드 `20260911`, 표준 라이브러리만 사용).

- 기간: 2024-01-01 ~ 2026-08-31 (기준일 = 2026년 8월 말 마감)
- 규모: 판매 26,194행, 총매출 약 35.8억 원
- 인코딩: UTF-8 (BOM 포함)

## 테이블

| 파일 | 행 | 설명 |
|---|---|---|
| `판매.csv` | 26,194 | 주문 1건 = 1행. 주문번호, 주문일자, 매장코드, 제품코드, 수량, 정가, 할인율, 매출액, 원가 |
| `제품.csv` | 40 | 제품코드, 제품명, 카테고리(5), 하위카테고리, 정가, 원가율 |
| `매장.csv` | 20 | 매장코드, 매장명, 시도, 권역, 채널(오프라인/온라인), 개점일 |
| `목표.csv` | 160 | 목표월(월 1일), 카테고리, 목표매출액. 2025년부터는 전년 동월 실적 × 1.06 |

- `매출액 = 수량 × 정가 × (1 − 할인율)`, `원가 = 수량 × 정가 × 원가율`
- 날짜 테이블은 일부러 넣지 않았다. 날짜 테이블을 만드는 것도 모델링 도구가 할 일이기 때문이다.
